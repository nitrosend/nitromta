# NitroMTA artwork

**Your mail. Your metal.**

The Dispatch identity pairs a segmented N with vermilion (`#FF4D00`),
graphite (`#181614`) and chalk (`#F5F2EC`).

- `logo-light.svg` and `logo-dark.svg`: transparent wordmarks for light and
  dark surfaces. Use at 160 px wide or larger.
- `mark.svg`: standalone symbol. Use at 24 px wide or larger.
- `avatar.svg` and `avatar.png`: square identity for repository avatars.
- `hero-light.jpg` and `hero-dark.jpg`: README banners, 2172 × 724.
- `delivery-path-light.svg` and `delivery-path-dark.svg`: the product's
  submission and direct-delivery path.
- `social-card.png` and `social-card.svg`: repository social preview and
  launch artwork, 1280 × 640 and under 1 MB.

Use the SVG masters for functional logos; keep their geometry, proportions
and clear space. The wordmarks contain outlined Sora ExtraBold lettering,
so they do not need an installed font or network request. Diagrams also use
outlined Sora and JetBrains Mono.

Type sources: [Sora](https://github.com/sora-xor/sora-font) and
[JetBrains Mono](https://github.com/JetBrains/JetBrainsMono), both under the
SIL Open Font License. No font software is bundled in this directory.

The main README uses the
[GitHub picture pattern](https://github.blog/changelog/2022-08-15-specify-theme-context-for-images-in-markdown-ga/)
to select a banner by color scheme. Its prose and image alternatives carry
the product description independently of the artwork.
