# NitroMTA artwork

**Your mail. Your metal.**

The Dispatch identity pairs a segmented N with vermilion (`#FF4D00`),
graphite (`#181614`) and chalk (`#F5F2EC`).

- `logo-light.svg`: the wordmark, graphite lettering beside the vermilion
  symbol, at the top of the README.
- `delivery-path-light.svg`: the product's submission and direct-delivery
  path, in the README.

Both contain outlined Sora and JetBrains Mono, so they need no installed
font or network request. Type sources:
[Sora](https://github.com/sora-xor/sora-font) and
[JetBrains Mono](https://github.com/JetBrains/JetBrainsMono), both under the
SIL Open Font License. No font software is bundled in this directory.

The README shows each in its light form alone: a README's color-scheme
switch follows the reader's operating system, not GitHub's own theme, so a
light and dark pair can show the wrong one. Its prose and image
alternatives carry the product description independently of the artwork.
